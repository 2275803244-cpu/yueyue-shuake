# 玥玥刷客

一个 Manifest V3 Chromium 扩展。采用网页内可拖动小浮窗作为任务控制台，按站点保存配置，可自动播放/恢复 HTML5 视频、阅读课件、调整倍速、切换下一节，还可连接采用 Chat Completions 格式的第三方 AI 接口识别并填写页面题目。

## 下载

直接下载打包好的扩展：[release/yueyue-shuake-v3.5.3.zip](release/yueyue-shuake-v3.5.3.zip)，解压后按下面“安装”步骤加载即可；也可以克隆本仓库直接加载根目录。

## 安装

1. 打开 Chrome/Edge 的扩展管理页：`chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开课程页面，右下角会出现“玥玥刷客”浮窗；开启“启用当前站点”即可运行。拖动深色标题栏可移动，点击扩展图标可隐藏或重新显示。

## 配置第三方 AI 答题

1. 点击浮窗中的“模型设置”，在独立设置页选择服务商。
2. 填写该平台的 API Key；扩展会自动填入兼容接口地址和常用模型名。
3. 如果服务不使用 `Authorization: Bearer ...`，修改“认证请求头”和“认证前缀”；还可用 JSON 填写附加请求头。
4. 点击“测试 AI 接口”，确认测试题能返回结构化答案。
5. 回到课程页面，点击浮窗的“立即答题”；确认识别正确后，再按需打开“自动答题”。

默认不会自动提交答案。“普通题提交”打开后，仅当本轮识别出的每道题都成功填写时才提交。学习通章节测验会调用页面原生 `btnBlueSubmit()`，随后调用 `submitCheckTimes()` 完成确认；失败时浮窗会显示具体原因，不再把“已填写”误报成“已提交”。

## 3.5.4 修复误报

- “立即答题”失败时不再一律报“所有 frame 均未识别到题目”：若某 frame 已识别到题目但 AI 请求失败（如未配置 API Key、接口超时、上一轮答题仍在进行），浮窗会显示真实原因和识别数量。

## 3.5.3 提升答题准确率

- 新增“高准确率模式”（默认开启，设置页可关）：每道题单独请求，再由 AI 以阅卷审核员身份独立复核候选答案，两轮一致才落卷；并发 3 路控制耗时。关闭后退回整组单次请求的旧模式。
- 提示词加入应试规则：多选题逐个选项独立判断、拿不准不选，判断题警惕“都/一定/必须/所有”等绝对化表述，只依据题干与选项字面信息作答。
- 设置页新增“启用答案缓存”开关；缓存键已包含模式与提示词，切换模式或改提示词都会重新请求。
- 高准确率模式下单题失败不影响其他题，全部失败才报错；任务详情中的“请求 N 次”显示真实请求次数。

## 3.5.2 改进

- 填空题支持多空：题目负载带 `blanks` 空数，AI 按空顺序返回 `textAnswers` 数组，逐空回填；全部空都填上才计为“已填写”，避免带空自动提交。
- 答案缓存键纳入系统提示词（改提示词不再命中旧答案），并增加 7 天有效期，过期自动重新请求。
- 设置页保存改为合并写入，不再丢弃表单之外的配置项（如后台的 `enableCache`）。
- 任务详情里的答案预览适配 `textAnswers` 多空显示，并过滤 AI 返回的无效选项索引。

## 3.5.1 修复

- 判断题“对/错”单字选项现在会正确归一化为“正确/错误”，AI 返回的选项原文可精确匹配。
- 章节完成检测不再把“未完成/待完成”误判为已完成，也排除了 `jobUnfinishCount` 等未完成类名的误匹配。
- 只点击浮窗标题栏而不拖动时，不再把无效位置写入存储（此前浮窗会在下次打开时跳到左上角）。
- 页面 DOM 变化触发的扫描增加 200ms 节流，降低动态页面的 CPU 占用。
- 扩展重载后旧页面的初始化报错降级为控制台警告；关闭标签页时同步清理“下一节”请求锁。

## 3.5 学习通章节测验、未完成任务保护与可自定义浮窗

- 浮窗显示当前运行状态、视频/课件/题目数量和正在处理的任务。
- 浮窗可拖动、折叠和关闭；位置、折叠状态会自动保存。
- 点击标题栏齿轮可自定义 260–380px 宽度、70%–100% 透明度、紫/蓝/绿/玫红主题和精简模式，也可一键恢复默认位置与外观。
- 可直接控制站点启停、自动视频、自动课件、自动答题、自动下一节和播放速度。
- “完成即跳过”会连续确认当前任务的完成标记；已经完成、已提交或已交卷的任务不再重复处理，直接进入下一未完成章节。
- 学习通视频内的判断题/选择题会被当作最高优先级任务：即使顶层已经显示“任务点已完成”，也会先在子 iframe 中调用 AI 回答、自动提交并点击“继续学习”，弹题消失后才允许进入下一节。
- 学习通黄色的 `.ans-job-icon` 只表示“任务点”，不再被误判为完成。只有检测到明确完成标记后才会点击下一节；等待期间只轮询状态，不触碰导航按钮。若平台仍弹出“当前章节还有任务点未完成”，扩展会自动选择“去学习”作为最后一道保护。
- 学习通新版章节测验支持 `.TiMu/.newTiMu/.questionLi` 题目、`.fontLabel` 题干、`[class*="before-after"]` 选项和 `answertype` 题型。顶层启用状态会自动共享给跨域题目 iframe，“立即答题”也会扫描全部 frame。
- AI 选择题同时返回索引和选项原文；扩展优先按规范化后的选项原文精确匹配，匹配失败才回退索引，可避免常见的 0/1 起始索引偏差。判断题统一处理“对/错、正确/错误、True/False、√/×”。
- 点击扩展图标可切换浮窗显示；页面脚本缺失时会自动注入并重试。
- “模型设置”打开独立配置页，提供国内模型预设、连通性测试、页面选择器和请求兼容设置。

## 实时任务调度

3.5 版以任务类型适配器持续监听页面：学习通章节测验、视频互动题、普通作业、视频和课件分别处理。题目 iframe 与顶层页面共享启用和提交设置；章节测验先解析平台题型，再请求 AI、按选项原文校验回填，全部填写后才执行平台提交及确认。视频互动题仍保持最高优先级，外层完成检测和视频结束事件必须等待弹题消失。平台若明确返回“仍有任务点未完成”，调度器会撤销跳转并返回学习。

学习通的视频通常位于子 iframe，而章节导航位于顶层页面。2.1.1 起，视频结束事件会交给扩展后台在顶层页面依次尝试可见按钮、按钮文字、学习通 `PCount.next(...)` 和章节列表，不再局限于视频 iframe 内查找。

2.2 起加入了可观察的任务队列：每个视频、题目组、课件阅读和章节跳转会分别显示“等待 / 进行中 / 完成 / 失败”。AI 请求支持超时、失败重试和递增等待；章节切换会等待平台保存进度并按配置重试。教学课件/PDF 会自动识别阅读器、滚动到内容末尾并处理“下一页”；阅读完成后再进入下一节。学习通适配器会优先调用页面原生 `PCount.next(...)`，随后从课程树选择后续未完成任务点，失败时在任务队列保留章节数量、当前索引等诊断信息。

## 设计参考

本扩展调研了成熟开源项目 [OCS 网课助手](https://github.com/ocsjs/ocsjs)、[uXuexitongJS](https://github.com/unraous/uXuexitongJS) 和 [chaoxing-script-ai](https://github.com/kukuqi666/chaoxing-script-ai)。3.5 版重点对照了它们对 `.TiMu`、`.fontLabel`、`.newZy_TItle`、`answertype`、`btnBlueSubmit()` 与 `submitCheckTimes()` 的处理方式，并保持独立的 AI 结构化答案实现。

内置预设包括 DeepSeek、阿里云百炼通义千问、智谱 GLM、月之暗面 Kimi、硅基流动和火山引擎方舟。火山方舟需要将模型字段替换为控制台创建的推理接入点 ID（`ep-...`）。预设只是便捷初始值，平台调整模型名称后可直接编辑，扩展会自动切换到“自定义兼容接口”。

## 平台适配

扩展会先寻找常见的“下一节”按钮。如果无法自动跳转：

1. 在页面上右键“下一节”并选择“检查”。
2. 找到一个稳定且唯一的属性，例如 `#nextLesson`、`.next-course` 或 `[data-action="next"]`。
3. 点击浮窗的“模型设置”，将它填入独立设置页的 CSS 选择器并保存。

如果视频在跨域 iframe 中，扩展也会在 iframe 内检测；但 iframe 内的视频与父页面的“下一节”按钮分属不同域时，自动跳转可能需要针对该平台编写适配器。

题目识别依赖页面 DOM。若提示没有识别到题目，请在 AI 设置页配置四个 CSS 选择器：题目容器、题干、选项、提交按钮。每道题的容器必须分别匹配，题干和选项选择器则相对于该容器查询。

## 边界与排错

- 仅处理标准 HTML5 `<video>`；不绕过登录、验证码、考试、付费限制或平台风控。
- AI 密钥位于 `chrome.storage.local`，不会同步，但同一浏览器配置文件中具有相应权限的本地扩展环境仍可能访问。公共电脑上不要保存长期密钥。
- AI 答案可能有误；建议先使用“立即识别答题”检查题目选择器和模型输出，再开启自动提交。
- 浏览器可能阻止有声自动播放，因此默认静音。先手动点击一次页面通常可以解除限制。
- 页面更新后若按钮类名变化，请重新填写“下一节”选择器。
- 调试时按 F12，在 Console 中筛选“玥玥刷客”。
