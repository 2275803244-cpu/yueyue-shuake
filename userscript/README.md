# 玥玥刷客 · 用户脚本版（脚本猫 / 油猴）

与 Chrome 扩展版功能一致的单文件用户脚本：可拖动浮窗任务台、自动播放视频、阅读课件、切换下一节、AI 自动答题（学习通章节测验/视频弹题适配、多空填空、富文本编辑器、高准确率模式）。

## 安装

1. 浏览器安装脚本管理器：[脚本猫 ScriptCat](https://scriptcat.org/) 或 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开管理器面板 → 新建脚本 → 把 `yueyue-shuake.user.js` 的全部内容粘贴进去保存；
   或者直接把本文件拖入浏览器（管理器会弹出安装确认）。
3. 打开课程页面，右下角出现“玥玥刷客”浮窗；菜单里也有“显示/隐藏浮窗”入口。
4. 点浮窗的“AI 设置”选择服务商、填写 API Key，点“测试 AI 接口”确认可用后保存。
5. 开启“启用当前站点”，按需打开“自动视频 / 自动课件 / 自动答题 / 自动下一节”。

## 与扩展版的差异

- AI 请求通过 `GM_xmlhttpRequest` 直发，跨域由脚本管理器代理，无需 `host_permissions`。
- 设置面板内嵌在浮窗（“AI 设置”按钮），不再依赖扩展独立设置页。
- 跨 frame 协调使用 `postMessage`；学习通 `PCount.next`/`btnBlueSubmit` 通过 `unsafeWindow` 在页面上下文调用。
- 数据保存在脚本管理器存储（`GM_setValue`），按站点（origin）隔离；卸载脚本即清除。
- 学习通 font-cxsecret 字体反混淆同样内置（3.7.0 起）：题干/选项先解码再发给 AI。扩展版额外打包 NotoSansSC 字形指纹字典（约 840KB）加速识别；用户脚本版无内置字典，自动用页面候选字 canvas 兜底比对，首次识别会稍慢约 1 秒。字形识别思路源自 [GlyphCopy](https://github.com/AxisTech/glyphcopy)（MIT License）。

## 排错

- 答题没反应：先点“AI 设置 → 测试 AI 接口”；再点浮窗“复制诊断”，把剪贴板内容发给维护者即可定位。
- 题目识别不到：浮窗“复制诊断”会列出每道题的识别类型、空数与输入控件，用于反馈适配。
- 仅供个人学习研究，遵守平台规则，注意 AI 答案可能有误；计分测验请先人工核对。
